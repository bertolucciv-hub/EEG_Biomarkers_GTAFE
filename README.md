# EEG_Biomarkers — Atlas científico interativo (v4.3)

Edição HTML5 estática para GitHub Pages e Vercel. Abra `index.html` no navegador após extrair a pasta; para servir localmente, execute `python -m http.server` na raiz do projeto.

## Refinamento v4.3
- Sumário lateral e scripts associados removidos do código. O índice horizontal superior permanece.
- Boxes explicativos organizados pela altura natural do texto, sem células artificialmente esticadas.
- Melhor relação de proporção entre pranchas, esquemas científicos verticais 3:4 e respectivas explicações.
- Tipografia, espaçamento, legendas e cartões uniformizados.
- Breakpoints para desktop, tablet e celular; leitura mais confortável em telas pequenas.
- Banner GTAFE mantém o logotipo centralizado verticalmente.
- Visualizador em tela cheia, figuras e conteúdo científico foram mantidos.

Arquivo de customização visual: `assets/editorial-polish.css`. As fontes, figuras e legendas devem receber validação editorial antes de divulgação científica formal.
